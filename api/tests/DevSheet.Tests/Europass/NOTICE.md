# Europass Candidate XSD (third-party, unofficial)

The four `.xsd` files in this folder come from **[J0ker98/europass-cv](https://github.com/J0ker98/europass-cv)**
(folder `schema/`), copied unchanged on 2026-11-24 from the version last pushed on 2026-09-18.

- Licence: Creative Commons Attribution 4.0 International (CC-BY-4.0), full text in `LICENSE` next to this file.
- Author: the contributors of J0ker98/europass-cv.
- Changes: none.

The European Commission publishes no schema for the Europass "Candidate" format. This XSD was written from real
exports of the Europass editor and is **not official**; the live editor's import stays the final check. DevSheet
uses it only in tests, to validate the XML produced by `EuropassXmlExporter`. See `docs/EUROPASS.md`.
